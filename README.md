# BFU kurs för programmering nivå 1  

Den här BFU-kursen riktar sig till dig som ska läsa på NBI handelsakademin som kräver motsvarande programmering nivå 1 i förkunskaper. Denna kurs bedrivs helt på distans där varje avsnitt innehåller video, kodmaterial och övningar. När du gått igenom kursmaterialet ska du göra tentan i dugga.
